SEÇENEK 3: GERÇEK INGENICO (İstanbul — 5 dakika)
═══════════════════════════════════════════════════════════════════════════════

Gerçek Ingenico Terminaline bağlan.

HAZIRLIK:
  1. Terminal açılır
  2. Settings / Ayarlar → Ağ Ayarları bölümüne git
  3. Terminal IP'sini bul (genellikle 192.168.X.X)
  4. Varsayılan port: 8400

KASA AYARLANSI:
  $ python3 start_pos.py
  
  Kasa açılır → "⚙ POS Terminal Ayarları":
    • Mod: "ingenico"
    • IP: [terminal'in IP'si — örn 192.168.1.50]
    • Port: 8400
    • "🔌 Bağlantı Testi" → Çıkmazsa IP kontrol et
    • "💾 Kaydet"

TEST:
  1. Satış yap
  2. "💳 KREDİ KARTI" tık
  3. Terminal ekranında ödeme sayfası açılır (veya okuyucu/PINpad aktif olur)
  4. Müşteri kartını okuttur/PINi girer
  5. Kasada "✅ Ödeme onaylandı!" görünür

SORUN GIDERİCİ:
  ❌ "TCP bağlantısı başarısız"
    → PC ve Terminal aynı WiFi/LAN'da mı?
    → Terminal IP doğru mu? (ping ile test et)
    → Terminal açık mı? (menüde kontrol et)
    → Güvenlik duvarı port 8400'ü kapatmış mı?

  ❌ Bağlantı sağlandı ama ödeme başlamıyor
    → Terminal modunu kontrol et (BİKİ VS EFT vs internet)
    → Pos üreticisine başvur
